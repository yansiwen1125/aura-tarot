# 运行素材

此目录仅保留网页引用的素材与许可证。交付目录只保留实际用图，不包含源素材副本、整组预览及过程导出。

- `tarot/00.png`–`21.png`：22 张大阿卡纳，实际像素为 1000×1510。
- `tarot/back.png`：当前 Figma 牌背，实际像素为 200×302。
- `tarot/figma-cloth-310.png`：328×310 桌布节点的导出图，含原设计模糊效果。
- `tarot/subject-*.png`：五个角色推荐卡的透明主体。
- `tarot/avatars/00.png`、`01.png`、`06.png`、`14.png`、`18.png`：五个完整圆形头像，首页和聊天共用。
- `icons/`、`stars/`、`v5/`：Figma 图标、装饰和导航。
- `Rochester-Regular.ttf`：标题字体；许可见 `Rochester-LICENSE.txt` 和 `FONT-NOTICE.md`。

来源详见 [tarot/SOURCE.md](tarot/SOURCE.md) 以及各目录的 SOURCE.md。
